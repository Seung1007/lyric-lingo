# Lyric Lingo — 프로젝트 브리핑

## 배경
- 기존 기반: `lyric-assistant.streamlit.app` (성악 발음/딕션 도구, Streamlit 기반)
- 목표: "제1회 일상뒤집기 AI 어플 개발 공모전" (마감 2026.8.22) 출품
- 리프레이밍: 성악 전공자 대상의 좁은 딕션 도구 → **팝송/애니 OST로 외국어를 배우는 대중용 앱**

## 공모전 취지와의 연결
- 공모 주제: "일상의 귀찮음을 해소할 AI 기반 서비스 아이디어"
- 문제 정의: "외국어로 된 노래를 듣다가 발음이나 뜻이 궁금한데, 마땅히 확인할 도구가 없다"
- 이 불편함을 AI로 해결하는 서비스로 포지셔닝

## 기술 스택 전환 계획
- 기존: Streamlit (Python)
- 신규: Next.js + Supabase + Vercel
  - Next.js: 프론트엔드/라우팅
  - Supabase: DB, 인증, 곡/가사 데이터 저장
  - Vercel: 배포

## UI 구조
1. **탭 1: "노래로 배우기"** (메인, 대중 타겟)
   - 팝송/애니 OST 가사 기반 언어 학습
   - 발음, 뜻, 문법 포인트 표시
2. **탭 2: "성악 전문 모드"** (서브탭, 기존 기능 보존)
   - 기존 성악 딕션 분석 기능 유지
