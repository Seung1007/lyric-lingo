# Lyric Lingo — 발표자료 초안

제1회 일상뒤집기 AI 어플 개발 공모전 (마감 2026.8.22) 제출용

## 한 줄 요약
외국어 노래를 듣다가 "이 가사 뭐라는 거지?"라는 일상의 궁금증을, 발음·뜻·문법을 즉시 보여주는 AI 서비스로 해결한다.

## 문제 정의 — 일상의 불편함
- 팝송, 애니 OST 등 외국어 노래를 듣다가 발음이나 뜻이 궁금해질 때가 많다.
- 하지만 가사를 검색해도 정확한 발음(로마자 표기)이나 자연스러운 번역을 한 번에 확인할 도구가 마땅치 않다.
- 결국 가사 사이트, 번역기, 발음 검색을 따로따로 오가야 하는 번거로움이 생긴다.

## 솔루션 — Lyric Lingo
좋아하는 노래 가사를 고르면 원문 · 발음(로마자 표기) · 뜻을 한 화면에서 바로 보여주는 언어 학습 앱.

### 핵심 기능
1. **노래로 배우기** (메인, 대중 타겟)
   - 팝송/애니 OST 가사를 줄 단위로 원문 · 발음 · 뜻 함께 제공
   - 발음 듣기 버튼으로 실제 음성 청취 지원 (브라우저 TTS)
2. **성악 전문 모드** (서브탭)
   - IPA 기반 정밀 딕션 분석 — 원래 이 프로젝트의 출발점이었던 성악 발음 도구 기능을 그대로 보존
   - 성악 전공자도 함께 쓸 수 있는 확장성 확보
3. **AI 가사 분석 — "내 가사 직접 분석하기"** (양쪽 탭 공통, 핵심 AI 기능)
   - 사전 등록된 곡뿐 아니라, 사용자가 원하는 아무 가사나 붙여넣으면 즉시 분석
   - Google Gemini가 줄 단위로 로마자 발음 · 한국어 번역 · IPA · 성악 딕션 노트를 실시간 생성
   - 언어 자동 감지 — 어떤 언어의 가사든 붙여넣기만 하면 됨

## 차별점
- 단순 번역기가 아니라, "가사"라는 콘텐츠에 최적화된 학습 경험 (줄 단위 대조, 발음 표기 동시 제공)
- 정해진 3곡에 갇히지 않고, 사용자가 실제로 듣고 있는 아무 노래나 즉석에서 AI로 분석 — 이게 "일상의 불편함을 AI로 해결"이라는 공모전 취지와 가장 직접적으로 맞닿는 지점
- 이미 검증된 성악 딕션 분석 노하우를 대중용 언어학습으로 확장 — 좁은 전문 도구에서 넓은 사용자층으로 재포지셔닝

## 기술 스택
- Next.js (App Router) — 프론트엔드
- Google Gemini API (gemini-3.6-flash) — 가사 줄 단위 로마자/번역/IPA/딕션 노트 실시간 생성
- Web Speech API — 발음 듣기 (브라우저 내장 TTS, 별도 비용 없음)
- Supabase (Postgres, RLS) — 사전 등록 곡/가사/언어/사용자 데이터
- Vercel — 배포, GitHub 연동 자동배포
